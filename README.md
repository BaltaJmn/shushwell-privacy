# shushwell-privacy

Public web of **Shushwell**, a baby shusher for iPhone that listens for crying. Served at
<https://shushwell.baltajmn.dev/> by GitHub Pages from `main`, behind Cloudflare (CNAME `shushwell` to
`baltajmn.github.io`, proxied), like `countwell-privacy` and `bondwell-privacy`.

| Path | What it is |
|---|---|
| `index.html` | What the app does, price, support contact. Support and marketing URL in the App Store |
| `privacy/` | Privacy policy. The URL in the app's paywall and in the App Store |
| `legal.html` | Legal notice (LSSI art. 10), same owner details as the other apps' webs |
| `sw/` | Stylesheet and icons |

Terms of use are Apple's standard EULA. The app's code lives in `~/AndroidStudioProjects/Shushwell`.
